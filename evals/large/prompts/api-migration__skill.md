TASK. You are working in a small Python 3 project in your current directory. The modules under `app/` make HTTP calls through `oldnet.fetch(url, timeout_ms, retries=0)`, a deprecated client. Your job is to move every one of those calls to `newnet.Client().request("GET", url, timeout_s=..., max_attempts=...)` without changing how any `app/` function behaves. Then write `REPORT.md` with the number of call sites you replaced and the list of files you changed. The project has these parts. `oldnet/__init__.py` is the legacy client. `newnet/__init__.py` is the new client. `netcore/transport.py` is the wire both clients use, and there is no real network: `transport.send` always fails unless something replaces it. `tests/fake.py` provides `FakeTransport`, which swaps in a fake `send`, records every attempt as `(method, url, timeout_s)` and replays scripted outcomes. `tests/test_app.py` holds a few unit tests. `README.md` contains a migration table and the rule for counting call sites. Read the two client docstrings and the README before you change anything; they are short and they define the exact semantics you must keep. The job is a careful translation of each call site, with an equivalence check before and after.

HOW IT WILL BE MEASURED. Your copy of the project is graded after the session ends, with no further input from you. First, `python3 -m unittest discover -s tests -t .` must pass. Second, every public function and method in `app/` is run against `FakeTransport` under a range of scripted outcomes: success, transport failures with and without recovery, and HTTP 4xx and 5xx statuses. Each result is compared with the original code. Three things must match: (a) the return value; (b) whether an exception escapes, and its HTTP status (an escaping `oldnet.FetchError` with `.status = s` must now be a `newnet.RequestError` with the same `.status`, and it must be an `HTTPError` exactly when `s` is not None); (c) the exact sequence of wire attempts, meaning the same URLs in the same order, the same `timeout_s` values and the same number of attempts. Assume these hidden scenarios are broader than the visible tests. Third, `app/` must contain no remaining import of or call to `oldnet`. Fourth, `oldnet/`, `newnet/`, `netcore/` and `tests/` must be byte-for-byte unchanged. Fifth, `REPORT.md` must give the correct call-site count and the exact set of files whose contents you changed.

WHAT COUNTS. A correct migration translates each call so it is equivalent on the wire and to its callers. For example, `body = oldnet.fetch(url, 1000, 3)` inside `try/except oldnet.FetchError` becomes `body = newnet.Client().request("GET", url, timeout_s=1000 / 1000, max_attempts=3 + 1).raise_for_status().text` inside `try/except newnet.RequestError`. You may use simplified literals such as `timeout_s=1.0, max_attempts=4` when the value is a constant. When the timeout or the retry count is a variable or a parameter, convert it at the call site with `x / 1000` and `n + 1`. Keep every public signature, parameter name, default value and constant in milliseconds and extra retries as it is: `Poller(timeout_ms=..., retries=...)`, `search(..., timeout_ms=...)`, and `SEARCH_TIMEOUT_MS` / `SEARCH_RETRIES` in `app/settings.py`. Callers depend on those. Leave `app/settings.py` untouched. The following would pass a shallow check but do not count. Dropping `raise_for_status()`: newnet returns 4xx/5xx responses instead of raising, so the error path silently changes. Writing a wrapper in `app/` that imitates `oldnet.fetch` and returns plain strings while still raising `FetchError`. Re-exporting or importing oldnet under another name. Rounding the timeout differently from `timeout_ms / 1000`. Editing the tests or the libraries so that they pass.

WHAT YOU HAVE.
1. The project directory (read-write), containing `app/` (13 files, including `__init__.py` and `settings.py`), the library packages and the tests listed above. Only `app/` and the new `REPORT.md` may change.
2. Tools: Bash, Read, Edit, Write, Glob and Grep, plus Python 3 with the standard library only. You have no internet access and cannot install packages. Run the tests with `PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -t .`. The environment variable keeps `__pycache__` out of `app/`; if any `__pycache__` appears there, delete it.
3. `/tmp` (read-write) for scratch work: a snapshot of the original `app/` and your equivalence script. Nothing you create there is graded. Do not leave scratch files in the project directory.
4. A budget of 40 turns. Nobody will answer questions, so make reasonable assumptions and record them in REPORT.md. A sensible split is about 5 turns to read, 4 to snapshot and write the harness, 12 to edit (batch several call sites per turn where you can), 6 to verify and fix, and 2 for the report. Keep about 8 turns in reserve.

HOW TO WORK.
1. Before editing anything, copy `app/` to `/tmp/orig_app/`. Its modules use relative imports such as `from .settings import ...`, so import the copy as the package `orig_app`, with `/tmp` and the project root on `sys.path`. Then list every call site with Grep. A call site is one call expression that ends up in `oldnet.fetch`, however it was imported: `oldnet.fetch(...)`, a module alias such as `import oldnet as on`, or `from oldnet import fetch as <name>`. A call inside a lambda counts once. A nested call such as `fetch(fetch(a).strip())` counts as two. Mentions in comments and docstrings are not call sites. Write the list, with file and line for each, into `/tmp/notes.md` and keep that file updated, so that you can pick the work up again from it.
2. Translate each call by these rules, which come from the docstrings. The milliseconds timeout becomes `timeout_s=<ms> / 1000`, whether it was passed by position or by keyword. `retries=N`, whether passed by position or by keyword and with a default of 0, becomes `max_attempts=N + 1`. The return value becomes `.raise_for_status().text`, unless the original code caught and discarded every `FetchError` and never used the body. In that one case you may use `.raise_for_status()` alone, but the 4xx/5xx path must still raise inside the `try`. `except oldnet.FetchError` (or an alias, or the imported name) becomes `except newnet.RequestError`, and `exc.status` keeps working. Lambdas and nested calls have to stay lambdas and nested calls with the same evaluation order. Replace the `oldnet` imports with `import newnet`. You may keep one client per module, such as `_client = newnet.Client()`, or create one per call. Both behave the same because the timeout is always passed explicitly. Updating a comment that mentions oldnet in a file you are already editing is fine.
3. Measure equivalence yourself, because the visible tests cover only `weather`, `health` and `poller`. Write `/tmp/equiv.py`. For every public function or method in both `orig_app` and `app`, it should run the same inputs under a set of outcome scripts: `[]`, `["fail"]`, `["fail", 200]`, `["fail"] * 6`, `[404]`, `[500]` and `["fail", 503]`. For `feeds`, the fake body is JSON rather than a URL, so give that case its own fake whose index body is a URL. For each run, compare the return value or the exception (mapping class and `.status` as described under HOW IT WILL BE MEASURED) and compare `fake.calls`. For the parameterised APIs, include non-default arguments such as `Poller(url, timeout_ms=1500, retries=2)` and `search(q, page=2, timeout_ms=1234)`. Print only one line per mismatch and a final count, not full traces.
4. Fix each mismatch, re-run `/tmp/equiv.py` and the unit tests until both are clean, then grep `app/` for `oldnet` and `fetch(` to confirm that only comments remain.
5. Build the changed-file list by diffing against the snapshot (`diff -rq /tmp/orig_app app`, ignoring `__pycache__`), not from memory. Count the call sites from your list in step 1, then cross-check that the count equals the number of `.request(` calls you added.

RULES. Not allowed: (a) editing, adding or deleting anything in `oldnet/`, `newnet/`, `netcore/` or `tests/`, or in README.md; (b) changing the name, parameters, defaults or units of any public function, method, class or constant in `app/`; (c) keeping any import of or call to `oldnet` in `app/`, directly or through a shim; (d) catching exceptions more broadly or more narrowly than the original did (for example a bare `except`, or catching `ValueError`); (e) leaving scratch files, snapshots or `__pycache__` in the project directory. Allowed: adding private helpers or a module-level client inside an `app/` file, restructuring a line for readability as long as evaluation order and behaviour are identical, updating comments, and creating any files you like in `/tmp`.

HOW THE SESSION RUNS. The session ends when you stop or your 40 turns run out, so make sure REPORT.md is written before the budget is nearly spent. Submit the edited files in `app/` and `REPORT.md` at the project root. After that, add a short `Notes:` section. It should state any assumption you made. Note it if you saw an `app/` function that hits this case. It should also record the result of the final unit-test run and of `/tmp/equiv.py` (number of scenarios, number of mismatches). Your final message should summarise what you changed, the evidence that behaviour is unchanged, and anything you could not resolve.
